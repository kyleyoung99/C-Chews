# Remix of Savour's Palate Reset

Build a premium, high-converting pre-order landing page for a functional oral care brand called Savour. The site should have a modern, minimalist aesthetic similar to high-end skincare or specialty coffee brands. Use a React and Tailwind CSS architecture for a fast, modern build.

Visual Theme & Colors:

Global Aesthetic: Clean, clinical, and sophisticated.

Color Palette: Soft off-whites (crema) for the base, warm espresso accents for the Post-Coffee elements, and deep matte burgundy/charcoal for the Post-Wine elements.

Typography: Minimalist, geometric sans-serif fonts to mimic sleek aluminum tin packaging.

Core Sections Structure:

Hero Section: A dynamic toggle or split-layout design showcasing two distinct aluminum tins. Headline: "Reset Your Palate." Subheadline: "The 30-second swallowable chew to neutralize coffee and wine." Primary CTA Button: "Reserve Founders Batch".

The Mechanism (How It Works): A minimalist 3-step visual timeline explaining the physical texture. Step 1: "The Snap" (The satisfying bite). Step 2: "The Melt" (Endothermic cooling). Step 3: "The Wash" (Effervescent swish and swallow). Make sure to include an aspect of stain prevention.

The Ingredients Grid: A clean UI grid with simple vector icons detailing the functional base: Micro-encapsulated Mastic, Erythritol (Cooling), Sodium Bicarbonate (Stain Shield), and Botanicals (Cardamom, White Tea). Highlight the stain prevention asoects

Checkout/Waitlist Section: A high-contrast section at the bottom (and a sticky header button) featuring an email input field and a direct CTA to place a pre-order via a Shopify checkout link.

Functionality Requirements:

Ensure all CTA buttons are prominent and link to a placeholder checkout URL.

Make the layout strictly mobile-first, ensuring the visual toggles and ingredient grids stack perfectly on phone screens.

Implement smooth, subtle fade-in animations on scroll to elevate the premium feel.
